# Server

Live graphs of how the machine running CCOSEL is doing. It updates every 2 seconds, and each
graph shows about the last two minutes.

- **CPU load**: how busy the server's processors are.
- **Memory**: how much of the server's memory is in use.
- **Requests**: how many requests the server answered per minute, from every client.

Underneath, it shows the number of processors, how long the server has been running, and the
folder it is serving files from.

If the server stops answering, the dashboard says so and keeps the last readings on screen
until it is back.
